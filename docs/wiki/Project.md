Alpine CSP Forms is developed in the open at [UAMS-Web/statamic-alpine-csp-forms](https://github.com/UAMS-Web/statamic-alpine-csp-forms). It is released under the MIT license; see [LICENSE](https://github.com/UAMS-Web/statamic-alpine-csp-forms/blob/main/LICENSE).

## Report a problem

Open an issue at [https://github.com/UAMS-Web/statamic-alpine-csp-forms/issues](https://github.com/UAMS-Web/statamic-alpine-csp-forms/issues). Include the Statamic and add-on versions, the form tag you used, the browser console output, and whether the page sends a Content Security Policy header.

## Releases

Releases are published at [https://github.com/UAMS-Web/statamic-alpine-csp-forms/releases](https://github.com/UAMS-Web/statamic-alpine-csp-forms/releases). They are 0.x pre-releases until 1.0.0; the notes of a release that can break a host call it out first.

## Contribute

Changes go through a pull request that passes `composer ci`; see [Development](Development.md). Edit these pages in [`docs/wiki/`](https://github.com/UAMS-Web/statamic-alpine-csp-forms/tree/main/docs/wiki), never in the wiki itself.
